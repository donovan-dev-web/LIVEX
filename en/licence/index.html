25 Licence

What you may reuse.

LIVEX's code is under copyleft, and the content of this site is under CC BY 4.0 — under different conditions. Here is what applies to what.

25.1 In one table

Three regimes, one project.

Before reusing anything, identify what you are taking: code, text, or a distinctive sign. Each column below applies independently of the others.

LIVEX source code — SYNE, ECHOS, Launcher, syne-mock, site (excluding PRISM)GPL-3.0-or-later — LICENSE ↗Use, study, modify and redistribute, provided notices are kept, changes are stated, and any distributed derivative work is placed under the same licence with its corresponding source code.

25.2 Source code

GPLv3, with copyleft.

The code is distributed under the GNU General Public License, version 3.0 or any later version(SPDX: GPL-3.0-or-later). You may use, study, modify and redistribute it, including commercially, provided you retain the copyright and licence notices, state the changes made, and place any distributed derivative work under the same licence while supplying its corresponding source code.

The scope covers the code of SYNE, ECHOS, the Launcher, syne-mock and the site. The Unreal PRISM project (prism/), including the PRISM-LDK plugin, is not covered by the GPL: it remains subject to Epic Games' terms applicable to Unreal Engine.

The GPL does not require you to publish your code when you use LIVEX internally or expose it as a network service: the sharing obligation applies to distribution of the software or of a derivative work. LIVEX is not licensed under the AGPL.

The software is provided as is, without warranty. The full licence text is authoritative and is available in theLICENSE ↗ file.

25.3 Site content

CC BY 4.0, with attribution.

The texts, diagrams and illustrations of this site are placed under Creative Commons Attribution 4.0(CC BY 4.0). You may reuse, adapt and redistribute them, including commercially, provided you credit the author and indicate whether any changes were made.

Suggested attribution: “LIVEX — Donovan Chartrain, CC BY 4.0”, with a link tothis page or the original page.

25.4 Brand and logos

The name, with reservations.

“LIVEX”, and the names SYNE, ECHOS, PRISM andLauncher designate the project's components. Their descriptive use is free: speaking of “compatible with LIVEX” or “based on SYNE” is allowed. On the other hand, any reuse suggesting an affiliation, a sponsorship or an official origin is to be avoided.

25.5 Common cases

May I…

CaseAnswer
Reuse a text or diagram from this site in an articleYes, under CC BY 4.0 — credit the author and state whether you modified the original.
Use the SYNE engine in a commercial projectYes. The GPL allows commercial use, but if you distribute a derivative work it must remain under GPL-3.0-or-later and its source code must be provided.
Modify the code and redistribute itYes, provided the modified version is published under GPL-3.0-or-later, with the corresponding source code and a statement of the changes.
Integrate LIVEX into distributed proprietary softwareNo, unless the whole complies with the GPL: a distributed derivative work cannot add proprietary restrictions.
Distribute the Unreal PRISM project or the PRISM-LDK pluginUnder Epic Games' terms, not under the project GPL.
Publish a screenshot of the site or the logosReserved for descriptive or editorial use; do not alter the marks.
Suggest an affiliation or an official partnershipNo — the project is personal, with no supporting organisation.

If in doubt about a case not listed, open an issue: the answer will also help clarify this page.
