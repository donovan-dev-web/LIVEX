12 Download · Installation

Start LIVEX from source.

No installer is distributed. Here's how to run the stack from the repository, locally — this is a development environment, not a public service.

Read first. The development services run locally (127.0.0.1) and are not hardened for public exposure.

12.1 Prerequisites

What you need.

ToolVersionFor
.NET SDK10.0.4xxSYNE engine
Python3.11+ECHOS (observation, API)
Node.js20+syne-mock (integration)
Unreal Engine5.8PRISM and the PRISM-LDK plugin (outside V0.1 scope)
curl—Availability checks
12.2 Quick start

The stack in one command.

From the root of the repository:

./scripts/dev-stack.sh

The script prepares the Python environment, compiles SYNE, then starts the ECHOS API (port5000), SYNE (control 5181, WebSocket 5180) and ECHOS ingestion in order. It does not launch any simulation: SYNE remains in the Idle state until theStart command.

The API documentation is then available at http://127.0.0.1:5000/docs.

12.3 Without the full engine

The mock for integration.

To advance Unreal integration without starting SYNE:

cd syne-mock
npm ci
npm start -- config_prism.json

The mock follows the SYNE observability contract, but simplifies deliberation and pathfinding: it serves integration tests, not scientific results.

12.4 Local ports

Everything stays local.

ServiceAddressRole
SYNE WebSocket127.0.0.1:5180Snapshots and events from a controlled run.
SYNE HTTP127.0.0.1:5181Control of the server and starting runs.
ECHOS API127.0.0.1:5000Runs, metrics and analyses (API only).
syne-mock127.0.0.1:5180/5181Integration server (launched separately).
12.5 Tests

Check that everything works.

# SYNE
cd syne && dotnet test Syne.sln --configuration Release

# ECHOS (from the root)
echos/.venv/bin/python -m pytest -q

# Launcher
cd launcher && dotnet test Launcher.Tests.Unit

▲Experimental The paths given are indicative and follow the development repository.
