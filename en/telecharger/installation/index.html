12 Download · Installation

Install LIVEX step by step.

Download the package for your system, launch the LIVEX installer, then choose your components and folders. No .NET, Python or Node.js installation is needed.

LIVEX 1.0.0 is released for Windows 10/11 x64 and Linux x64. On Windows, download and extract the archive, then run livex-setup.exe. On Linux, extract the package and run ./livex-setup.

12.1 Download

Choose your platform and package.

Packages are published in the `livex-v1.0.0` public release. The installer and core are self-contained: you do not need to install .NET, Python, Node.js or Unreal Engine.

12.2 Launch the assistant

Start from the welcome screen.

  1. Extract the package you downloaded if your system has not already done so.
  2. Launch the installer: double-click livex-setup.exe on Windows; on Linux, run ./livex-setup from the extracted folder.
  3. Choose a language (French or English), then read and accept the licence to continue.
  4. Select components on the next screen. Launcher, SYNE and ECHOS are the required core; PRISM is included and selected by default.
  5. Choose locations for the software and workspace. Keep them separate: the workspace stores your experiments and reports.
  6. Review the summary, confirm, and let the assistant finish installing.
  7. Finish: choose “Launch LIVEX” on the result screen to open the Launcher.
12.3 Select components

The core, PRISM and optional modules.

  • Required core: Launcher, SYNE, ECHOS, contracts and resources.
  • PRISM: packaged 3D rendering application, selected by default. Unreal Engine is not needed to run it.
  • PRISM-LDK: optional Unreal plugin, provided as an archive for manual integration into an Unreal project you own.
  • Offline documentation and SYNE-Mock: optional modules for offline reference and integration development.

With core, an internet connection is needed if you select an optional module downloaded from the release. With full, those modules are already included. Installing the core and PRISM does not require a network connection.

12.4 System requirements

No application runtimes to install.

SystemYou needAlready included
Windows 10/11 x64A standard user account and the disk space listed in the release.Standalone installer, .NET, Python and component runtimes.
Linux x64 (glibc)Desktop display stack, `libicu` and `libssl` available on the distribution.Standalone installer, .NET, Python and component runtimes.

You do not need Unreal Engine or a development environment to use LIVEX or run PRISM. Unreal Engine is only required to develop PRISM or integrate PRISM-LDK into your own project.

The installer does not require administrator privileges. It keeps the software folder separate from the workspace; uninstall options let you choose what to remove and protect research results according to your selection.

12.5 Update and support

Return to the installer when needed.

Run the installer again to update, repair or uninstall an existing installation. It detects LIVEX and shows the relevant maintenance options. If something goes wrong, keep the log path shown by the assistant.

For checksum verification, data locations and troubleshooting, see the full user guide. The source installation guide is for developers.
