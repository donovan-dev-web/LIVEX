24 Accessibility

Making the site readable for everyone.

This site targets level AA of the WCAG 2.2 rules. It is a voluntary statement: it describes commitments kept, and names what remains improvable.

24.1 Conformance target

WCAG 2.2, level AA.

The LIVEX site targets conformance with level AA of the Web Content Accessibility Guidelines (WCAG) 2.2. This is a voluntary statement, with no legal obligation attached to this personal project: the approach is chosen, not imposed.

We do not declare full conformance. An honest statement also sets out what has not yet been verified.

24.2 Measures implemented

What has been done.

Contrasts

Palette and tokens verified for text/background contrast, in both light and dark themes.

Visible focus

Every interactive element has a focus indicator visible from the keyboard.

Colour never alone

Statuses combine colour, symbol and text — never colour alone.

Alternative texts

Images and figures carry a relevant alternative; diagrams are described in text.

Keyboard navigation

The site can be browsed entirely with the keyboard, with a skip link to the content.

Light / dark theme

Light theme by default; manual dark toggle, remembered locally.

Reduced motion

The system setting prefers-reduced-motion is respected; no continuous animation.

Semantic structure

Hierarchical headings, a single h1 per page, named regions and landmarks.

24.3 Known limitations

What remains to be tested.

Accessibility was taken into account at design time, but no external audit has yet been carried out. Automated checks are not enough: certain uses (screen readers, voice navigation) require a human evaluation that remains to be done.

24.4 Report a defect

Your feedback improves the site.

If you encounter an accessibility barrier — insufficient contrast, an element unreachable from the keyboard, a missing alternative — report it. If possible, specify the page, the browser or the assistive tool used.
