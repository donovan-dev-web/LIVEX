08 Architecture · PRISM

Rendering.

PRISM (Perceptual Rendering & Interactive Simulation Module) gives form and presence to the simulated world. PRISM 1.0.0 is delivered for Windows and Linux.

Table of contents

●Available PRISM 1.0.0 · PRISM-LDK 1.0.0

PRISM-LDK 1.0.0 (Unreal module PrismLdk) exposes SYNE contracts to Blueprint. PRISM 1.0.0, built around the plugin, is packaged for Windows and Linux. Packaging confirms delivery of the applications; it does not mean every rendering function in the project vision is complete or validated.

8.1 Role

Making dynamics visible.

Where SYNE computes and ECHOS measures, PRISM renders the simulated world as a 3D scene. The Unreal project owns the environment, objects and visual representations, along with the interface and interactions used to inspect the world. It consists of the PRISM project and the integration pluginPRISM-LDK.

8.2 What PRISM does

A world computed by SYNE, rendered by Unreal.

PRISM receives the description of a prepared world, then the full snapshots and events sent by SYNE. It uses them to build or update the scene: each agent remains associated with its SYNE identifier, and displayed positions and states follow the authoritative state of the received tick. Visual effects can signal events without applying mutations a second time when they are already reflected in a snapshot.

PRISM can participate in an experiment's lifecycle: connect, prepare the presentation, confirm it is ready, then request start, pause, resume or stop using the contract. Decision-making, world progression and authoritative data remain in SYNE.

ElementResponsibility
Environment and objectsThe PRISM project chooses how to represent the logical world's dimensions and data in 3D.
AgentsThe scene creates and updates their representation while preserving their SYNE identifier.
InteractionThe interface can control the lifecycle and present received states and events.
SimulationSYNE alone owns the rules, decisions, ticks and authoritative state.

The Unreal project chooses its scene, scale, navigation and interface; the plugin does not generate them automatically.

8.3 PRISM-LDK / PrismLdk

The Unreal integration kit.

PRISM-LDK means LIVEX Development Kit; PrismLdk is the Unreal module name. This C++ plugin connects SYNE to the Unreal project. It exposes contracts, structures, control functions and events to Blueprints so PRISM can connect the transport and respond to updates without reimplementing the protocol.

  • Local WebSocket on port 5180: world descriptions, snapshots, deltas and events;
  • Local HTTP on port 5181: control commands and status;
  • Blueprint nodes to obtain the subsystem, configure and connect the client, send commands and receive results;
  • an actor registry indexed by SYNE identifier, exposed through the plugin's registry subsystem.

The plugin is packaged separately for Unreal Engine 5.8 projects. By itself it creates no terrain, actors, collisions, navigation, user interface or animations. It does not contain a parallel simulation engine.

8.4 Delivery and scope

Release status.

PRISM 1.0.0 is packaged for Windows and Linux and runs from the distribution without Unreal Engine installed. The 76 PRISM/PrismLdk Automation Specs executed for the release are validated: 71 passed, 5 passed with warnings, 0 failed.

Packaging and tests validate the behavior covered by their scenarios; they do not mean every feature described in the rendering specifications is complete. The roadmap details the work still evolving.

The project's roadmap is authoritative for the steps ahead.

Do not assume that local protections in the engine or mock secure distribution of the PRISM project. See SECURITY.md.
