06 Architecture · SYNE

The engine.

SYNE (Systems & Emergent Network Engine) drives the simulated world. It is deterministic: from the same seed, a run replays identically.

▲Experimental SYNE 0.15.0 · .NET engine (repository)

Experimental: the engine is functional in the repository, but no public distribution exists to date.

6.1 Role

Set rules, let them play out.

SYNE defines a world (space, resources, time) and agents that act according to explicit rules. At each tick, the world advances one deterministic step: no decision is left to unrecorded randomness.

The engine produces a snapshot — a structured picture of the world state — and an event trace. It is this trace, not the engine, that drives observation.

6.2 Determinism

The same start, the same run.

Bit-for-bit determinism is a contract: replaying a run with the same seed must reproduce exactly the same trajectory. This is what makes a result verifiable and a measurement reproducible.
