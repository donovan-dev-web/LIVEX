25.2 Code source

GPLv3, avec copyleft.

Le code est distribué sous licence GNU General Public License, version 3.0 ou toute version ultérieure (SPDX : GPL-3.0-or-later). Vous pouvez l'utiliser, l'étudier, le modifier et le redistribuer, y compris à des fins commerciales, à condition de conserver les mentions de copyright et de licence, de signaler les modifications apportées, et de placer toute œuvre dérivée distribuée sous la même licence en fournissant son code source correspondant.

Le périmètre couvre le code de SYNE, ECHOS, du Launcher, de syne-mock et du site vitrine. Le projet Unreal PRISM (prism/), y compris le plugin PRISM-LDK, n'est pas couvert par la GPL : il reste soumis aux conditions d'Epic Games applicables à Unreal Engine.

La GPL n'impose pas de publier votre code lorsque vous utilisez LIVEX en interne ou lorsque vous l'exposez comme service réseau : l'obligation de partage porte sur la distribution du logiciel ou d'une œuvre dérivée. LIVEX n'est pas sous AGPL.

Le logiciel est fourni en l'état, sans garantie. Le texte complet fait foi et figure dans le fichierLICENSE ↗.
