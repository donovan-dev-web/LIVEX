05 Architecture

Un pipeline, trois responsabilités.

LIVEX relie trois composants par des contrats explicites. Le monde produit des traces, l'observation les mesure, le rendu les donne à voir — sans jamais mélanger les rôles.

Sommaire
5.1 Vue d'ensemble

Du monde à la perception.

monde SYNE traces ECHOS mesures PRISM perception

Chaque étage est indépendant et versionné séparément : un composant peut être remplacé sans casser les autres, pourvu que les contrats de transport et de persistance soient respectés. C'est ce découplage qui rend la pile testable et évolutive.

5.2 Les composants

Trois blocs, trois états déclarés.

Systems & Emergent Network Engine

SYNE

Moteur déterministe de simulation multi-agents : règles, monde, ticks et rejouabilité bit-à-bit à partir d'une graine.

▲Expérimental

Moteur fonctionnel dans le dépôt (0.17.0) ; aucune distribution publique à ce jour (octobre 2026).

Détails →
Emergent Cognition & Holistic Observation System

ECHOS

Ingestion, analyse et API headless : lecture des runs, métriques de viabilité, détection de boucles et de motifs émergents.

▲Expérimental

API headless fonctionnelle dans le dépôt (paquet 0.1.0) ; non distribuée publiquement.

Détails →
Perceptual Rendering & Interactive Simulation Module

PRISM

Rendu perceptif et module de simulation interactive : projet Unreal et plugin d'intégration PRISM-LDK.

◆En développement

Projet Unreal et plugin PRISM-LDK en version de travail ; l'expérience de rendu est hors périmètre V0.2.

Détails →

Captures réelles pour ECHOS et PRISM ; pour SYNE, un schéma conceptuel — un moteur n'a pas d'interface à capturer. Ces visuels datent de la version de développement (octobre 2026) : aucun ne vaut démonstration d'une version publiée.
