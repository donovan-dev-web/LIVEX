12 Télécharger · Installation

Installer LIVEX pas à pas.

Téléchargez le paquet correspondant à votre système, lancez l'assistant LIVEX et choisissez vos composants et dossiers. Aucune installation de .NET, Python ou Node.js n'est nécessaire.

LIVEX 1.0.0 est publié pour Windows 10/11 x64 et Linux x64. Sur Windows, l'assistant est autonome : téléchargez l'archive, extrayez-la, puis lancez livex-setup.exe. Sur Linux, extrayez le paquet et lancez ./livex-setup.

12.1 Télécharger

Choisir la plateforme et le paquet.

PaquetContenuTéléchargement
Windows x64 · coreSocle LIVEX et PRISM ; modules facultatifs téléchargés si vous les choisissez.Télécharger ZIP ↗
Windows x64 · fullSocle, PRISM et modules facultatifs embarqués, pour une installation hors ligne.Télécharger ZIP ↗
Linux x64 · coreSocle LIVEX et PRISM ; Internet requis pour les modules facultatifs choisis.Télécharger TAR.GZ ↗
Linux x64 · fullSocle, PRISM et modules facultatifs embarqués, pour une installation hors ligne.Télécharger TAR.GZ ↗

Les fichiers sont fournis dans la release publique `livex-v1.0.0`. L'installateur et le socle sont autonomes : vous n'avez pas à installer .NET, Python, Node.js ou Unreal Engine.

12.2 Lancer l'assistant

Un accueil pour démarrer.

  1. Extraire le paquet téléchargé dans un dossier, si le système ne l'a pas déjà fait.
  2. Lancer l'installateur : double-cliquez sur livex-setup.exe sous Windows ; sous Linux, lancez ./livex-setup depuis le dossier extrait.
  3. Choisir la langue (français ou anglais), puis lire et accepter la licence pour poursuivre.
  4. Choisir les composants dans l'écran suivant. Le Launcher, SYNE et ECHOS forment le socle obligatoire ; PRISM est inclus et sélectionné par défaut.
  5. Choisir les emplacements du logiciel et de l'espace de travail. Gardez-les séparés : l'espace de travail accueille vos expériences et rapports.
  6. Relire le récapitulatif, confirmer, puis laisser l'assistant terminer l'installation.
  7. Terminer : sur l'écran de résultat, choisissez « Lancer LIVEX » pour ouvrir le Launcher.
12.3 Choisir les composants

Le socle, PRISM et les modules facultatifs.

  • Socle obligatoire : Launcher, SYNE, ECHOS, contrats et ressources.
  • PRISM : application de rendu 3D packagée, sélectionnée par défaut. Unreal Engine n'est pas nécessaire pour la lancer.
  • PRISM-LDK : plugin Unreal facultatif, livré sous forme d'archive à intégrer manuellement dans un projet Unreal que vous possédez.
  • Documentation hors ligne et SYNE-Mock : modules facultatifs destinés à la consultation sans réseau et au développement d'intégrations.

Avec core, une connexion Internet est nécessaire si vous cochez un module facultatif téléchargé depuis la release. Avec full, les modules sont déjà dans le paquet. L'installation du socle et de PRISM ne demande pas de connexion réseau.

12.4 Prérequis système

Pas de runtime applicatif à installer.

SystèmeCe qu'il fautCe qui est déjà fourni
Windows 10/11 x64Un compte utilisateur standard et l'espace indiqué sur la release.Installateur autonome, .NET, Python et runtimes des composants.
Linux x64 (glibc)Bureau graphique, `libicu` et `libssl` disponibles sur la distribution.Installateur autonome, .NET, Python et runtimes des composants.

Ni Unreal Engine ni un environnement de développement ne sont requis pour utiliser LIVEX ou lancer PRISM. Unreal Engine est requis seulement si vous développez PRISM ou intégrez PRISM-LDK dans votre propre projet.

Le parcours ne demande pas de droits administrateur. Il sépare le dossier du logiciel de l'espace de travail ; la désinstallation permet de choisir ce qui est retiré et protège les résultats de recherche selon l'option sélectionnée.

12.5 Mise à jour et aide

Reprendre le parcours plus tard.

Relancez l'installateur pour mettre à jour, réparer ou désinstaller une installation existante. Il détecte LIVEX et affiche les opérations de maintenance appropriées. En cas de problème, conservez le journal indiqué par l'assistant.

Pour les instructions de vérification des sommes, l'emplacement des données et le dépannage détaillé, consultez le guide utilisateur complet. Le guide d'installation depuis les sources s'adresse aux développeurs.

12.6 · Commencer

Télécharger LIVEX 1.0.0

Choisissez Windows ou Linux et le profil adapté à votre connexion.
