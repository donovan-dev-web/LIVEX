## Maintenance

Les décisions d’architecture pérennes sont conservées dans les ADR des composants. Les changements de comportement sont consignés dans leurs changelogs, contrats et tests. Les rapports de [`realignment/`](realignment/README.md) conservent les résultats synthétiques, protocoles, versions, limites et suites de vérification utiles, sans archiver les sorties brutes ni les artefacts temporaires.
