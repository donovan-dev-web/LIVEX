# Dossier de gouvernance — LIVEX

Ce dossier regroupe les décisions, l’état du projet et les rapports de validation pérennes. Les documents de référence par composant restent dans leurs dossiers respectifs.

## Contenu

| Document | Description |
|---|---|
| [`LIVEX-STATUS.md`](LIVEX-STATUS.md) | État observé du projet et de ses composants. |
| [`LIVEX-PERFORMANCE-2026-10.md`](LIVEX-PERFORMANCE-2026-10.md) | Relevé de performance et de tests : comptage, benchmarks par composant et par scénario, capacité maximale et configuration d’exécution minimale/recommandée. |
| [`ROADMAP.md`](ROADMAP.md) | Jalons transverses et backlog unifié. |
| [`realignment/README.md`](realignment/README.md) | Index des rapports versionnés de réalignement et de validation, organisés par version et composant. |
| `GITFLOW.md`, `ISSUES.md`, `KANBAN.md` | Conventions de contribution et suivi du projet. |

## Maintenance

Les décisions d’architecture pérennes sont conservées dans les ADR des composants. Les changements de comportement sont consignés dans leurs changelogs, contrats et tests. Les rapports de [`realignment/`](realignment/README.md) conservent les résultats synthétiques, protocoles, versions, limites et suites de vérification utiles, sans archiver les sorties brutes ni les artefacts temporaires.
