    Class ActionCatalog

    Catalogue déclaratif des actions (SYNE-040) : pour chaque DesireKind, une ActionDefinition issue de la configuration agents.actions.catalog. L'ordre du catalogue (ordre de l'enum) est l'ordre stable de départage (décision n°22), les actions sont vérifiées viables contre l'état des réserves.
