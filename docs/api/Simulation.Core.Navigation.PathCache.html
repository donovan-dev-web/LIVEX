    Class PathCache

    Cache LRU de chemins (SYNE-077, Monographie §6.2.12) : mémoïsation d'un calcul A* par paire (cellule source, cellule but) afin d'éviter de re-planifier le même chemin à chaque tick de déplacement. Borné : la plus ancienne entrée est évincée au-delà de Capacity.

    Déterminisme : l'ordre d'accès est l'ordre d'appel (lui-même déterministe) ; le remplacement et l'éviction ne consomment aucun tirage du PRNG global.
