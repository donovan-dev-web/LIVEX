    Class ReproductionSettings

    Cycle de vie — naissance par fusion consentie (SYNE-062/075, décisions n°17, 16, SYSTEM_SPEC.md §8, Monographie §6.6.2) : fusion rare et volontaire, décision déterministe sans PRNG. La « fusion consentie » est soumise aux conditions de fidélité comportementale (proximité physique, ligne de vue, énergie suffisante, absence de besoin critique) — SYNE-075.
