    Class TerritorySettings

    Zones de territoire (SYNE-073, décision n°21, CONFIGURATION.md §6.10) : world.territories. V0.1 : la présence d'une entité dans une zone délimite le territoire effectif (vue d'observation) — appartenance suivie en fin de tick (0 tirage PRNG, DETERMINISM.md §3) et émise en world.territory_membership_changed. Désactivé par défaut ⇒ trajectoire du scénario de référence inchangée (re-pin contractuel). Les sources spatiales de ressources autour des points de survie (ressources du territoire) restent hors V0.1 (SYSTEMS_SPEC.md §4).
