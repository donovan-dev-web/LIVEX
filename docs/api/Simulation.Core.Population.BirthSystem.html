    Class BirthSystem

    Cycle de vie — naissance par fusion consentie (SYNE-062/075, décisions n°17/16, SYSTEM_SPEC.md §8, Monographie §6.6.2) : une fusion reste côté cycle de vie, l'entité née a un état cognitif vierge qui réinitialise la boucle de vie.

    Exécuté après la boucle des entités et la communication de masse (ordre causal strict, DETERMINISM.md §5) : la population ne mute jamais pendant l'itération.

    V0.2 : mécanique déterministe sans PRNG —

    1. une tentative de fusion au plus tous les intervalTicks (rareté, V0.1 → V0.2) ;
    2. le consentement est la confiance réciproque (min des deux sens) ≥ consentTrustThreshold (§6.6.2) ;
    3. la fidélité de la fusion (SYNE-075, Monographie §6.6.2) exige en plus : proximité physique (mergeRange), ligne de vue dégagée (requireLineOfSight), énergie suffisante des deux parents (mergeMinimumEnergy) et absence de besoin critique chez les deux parents (requireNoCriticalNeed) ;
    4. première paire qualifiante dans l'ordre trié des identifiants (moindre id = mère, suivant = père) — aucun choix stochastique ;
    5. l'enfant naît au point médian des parents (borné au monde), id = plus grand id existant + 1, traits fusionnés (dominance/mutation configurables, SYNE-063) et les parents sont conservés (couple non dissous).
