    Class UtilityEvaluator

    Évaluateur d'utilité (COGNITIVE_ARCHITECTURE.md §6, décision n°13) : U = (benefit − cost − risk) × confidence × personalityModifier + urgency. Bonus d'alignement ×1.2 si l'action rejoint l'objectif courant ; sélection par utilité maximale, départage déterministe par ordre du catalogue (SYNE-030).
