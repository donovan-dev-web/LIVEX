    Struct Xoshiro256StarStar

    Générateur pseudo-aléatoire déterministe xoshiro256** (Blackman & Vigna).

    Type valeur immuable : chaque tirage renvoie le résultat ET l'état suivant. Pour une même graine et un même nombre de tirages, la séquence est identique bit-à-bit quelle que soit la plateforme — les trajectoires de simulation restent reproductibles (cf. DETERMINISM.md, arrêt d'utilisation de System.Random).
