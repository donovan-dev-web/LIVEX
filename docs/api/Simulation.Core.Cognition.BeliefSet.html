    ApplyEvidence(Fact, double, string, BeliefSettings, ulong)

    Applique une observation (COGNITIVE_ARCHITECTURE.md §4) :

    • fait inconnu → création à la confiance du signal ;
    • même fait, même source → alignement (+0.2, max 1.0) ;
    • même fait, source différente → moyenne des confiances ;
    • fait contradictoire (même sujet + prédicat, valeur différente) → conflit (−0.1, min 0.1) sur les croyances concurrentes existantes + création d'une nouvelle croyance au signal.
