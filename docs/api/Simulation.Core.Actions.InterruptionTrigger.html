    Class InterruptionTrigger

    Déclencheur d'interruption d'action centralisé (SYNE-043, décision n°15) : unique point de décision « l'action en cours est-elle interrompue par un besoin urgent ? ». Les règles sont déclaratives (besoin critique faim/énergie) et évaluées facialement à n'importe quel tick, y compris entre deux délibérations (holdover, COGNITIVE_ARCHITECTURE.md §6).

    Contrat de déterminisme : évalue par utilité (même formule que la délibération), aucune consommation du PRNG ; en cas d'égalité, l'ordre du catalogue tranche.
