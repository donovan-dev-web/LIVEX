    Class Group

    Groupe émergent (SYNE-060, SYSTEM_SPEC.md §5, décisions n°23/24) : ensemble d'entités liées par une cohésion (confiance réciproque × parts communes de croyances / buts partagés). Les structures émergent — aucun script de coalition. Modèle mutable, mis à jour par GroupSystem à chaque révision.
