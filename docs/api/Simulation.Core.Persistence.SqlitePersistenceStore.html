    Class SqlitePersistenceStore

    Store SQLite V2.0 (SYNE-110, PERSISTENCE.md §3 — Annexe G) : schéma relationnel de 11 tables, transactions atomiques (PERSISTENCE.md §5) et rotation de maxBackups runs. Le snapshot bit-à-bit complet (monde + cognition + RNG 4×64) est conservé dans tick_states.state/rng_state pour la reprise exacte (PERSISTENCE.md §4). Les tables agents/ressources/groupes/événements/ messages/metrics restent le pendant relationnel requis par le schéma.
