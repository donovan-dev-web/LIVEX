    Class SimulationSnapshot

    Snapshot bit-à-bit de l'état de simulation à un instant T (SYNE-111, PERSISTENCE.md §4) : ne capture que les états mutables durables — le reste (grille spatiale, cache de chemins, buffers par-tick) est reconstruit déterministiquement à la restauration.
