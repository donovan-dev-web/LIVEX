    Class GroupSystem

    Système de groupes émergents (SYNE-060/061, SYSTEM_SPEC.md §5, décisions n°23/24). Il n'invente aucune coalition scriptée : les groupes naissent de la cohésion constatée entre les entités — confiance réciproque × affinité (croyances partagées + buts partagés).

    Exécuté à fréquence reviewIntervalTicks (LOD déterministe), après le pipeline cognitif et la communication de masse (ordre causal strict) :

    1. Liens sociaux : paires (entité, entité) en confiance réciproque ≥ trustThreshold partageant au moins une croyance ou un but — la « proximité sociale » (décision n°24) ;
    2. Composantes connexes du graphe = candidats groupes (union-find déterministe, racine = plus petit id) ; taille ≥ minGroupSize ;
    3. Cycle de vie : continuité par ensemble de membres identique (même id, durée cumulée) sinon formation / dissolution ;
    4. Leader émergent (SYNE-061) : membre de plus forte confiance entrante intra-groupe (départage par id minimal) ;
    5. Décisions collectives (SYNE-061) : adoption par quorum consensusThreshold sur l'intention dominante des membres.

    Déterminisme : aucun tirage du PRNG global ; toutes les itérations suivent des ordres triés par identifiant (DETERMINISM.md §3).
