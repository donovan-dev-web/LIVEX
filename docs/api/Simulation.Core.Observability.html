    Namespace Simulation.Core.Observability

    Classes

    AgentSnapshot

    État d'une entité dans un WorldSnapshot (API_CONTRACTS.md §2.1). V0.1 : identité, espèce, position, besoins, intention, et cognition observable (traits, croyances, objectifs, relations de confiance, volume mémoire) — nourrit les moteurs de métriques ECHOS (jalon U2).

    BeliefObservation

    Observation d'une croyance (fait + confiance) — snapshot agent, API_CONTRACTS.md §2.1.

    BookSnapshot

    Livre au snapshot (SYNE-121, décisions n°18/19, Monographie §3.18) : identifiant, auteur, titre, tick d'écriture (poinçonné par la boucle, writtenTick) et liste des lecteurs distincts (ordre de première consultation, readCount = taille redondante mais explicite). Émise quand world.books.enabled est actif (désactivé par défaut).

    EventSensor

    Production d'événements discrets à partir de la cognition (SYNE-080).

    ExternalEvent

    Événement discret typé (API_CONTRACTS.md §2.2 — ExternalEvent). V0.1 : tick_summary (1 par tick) et decision_made (1 par entité par tick).

    GoalObservation

    Observation d'un objectif (type + âge en ticks) — snapshot agent.

    GroupSnapshot

    Groupe émergent dans le snapshot (SYNE-060/061, API_CONTRACTS.md §2.1) : identifiant, membres triés, leader et dernière décision collective.

    ObservabilityContract

    Contrat d'observabilité (SYNE-080, API_CONTRACTS.md §2) : messages JSON camelCase sur WebSocket, versionnés. Chaque message est un objet avec un champ type ("snapshot" ou "event").

    ObservabilitySerializer

    Sérialisation déterministe camelCase des messages d'observabilité (API_CONTRACTS.md §2). Les objets JsonObject préservent leur ordre d'insertion → sortie stable et testable (checksum d'émission).

    ObstacleSnapshot

    Obstacle statique (construction, SYNE-071, API_CONTRACTS.md §2.1).

    ResourceSnapshot

    État d'une réserve globale dans le snapshot (SYNE-042, API_CONTRACTS.md §2.1).

    TerritorySnapshot

    Zone de territoire au snapshot (SYNE-073, décision n°21, API_CONTRACTS.md §2.1) : disque « point de survie » + members courants (identifiants croissants, memberCount = taille, redondante mais explicite à l'émission JSON).

    TrustObservation

    Observation d'une relation de confiance (pair + niveau 0-1) — snapshot agent.

    WorldSnapshot

    Photographie du monde à un tick (API_CONTRACTS.md §2.1 — WorldSnapshot). Représentation pure, sérialisée en camelCase par ObservabilitySerializer.
