    Class ObjectPool<T>

    Pool d'objets réutilisables (SYNE-092, PERFORMANCE.md §5) : réduit la charge GC des structures éphémères (listes de candidats de perception, scores…) sans changer le comportement — un objet rendu est vidé avant ré-emprunt, et l'ordre des éléments produits reste identique à une allocation « fraîche » (aucun PRNG, aucune influence sur la trajectoire — DETERMINISM.md §3).
