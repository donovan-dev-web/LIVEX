    Class SimulationLoop

    Boucle de simulation (SYNE-002, SIMULATION_LOOP.md §1).

    • 1 tick = 1 minute simulée (défaut) — SimulationTime.
    • Respect de maxTicks : la boucle s'arrête après le tick n° maxTicks.
    • L'état du PRNG avance d'un tirage par tick (flux ancré au tick index).
    • Depuis U1 : pipeline cognitif BDI (perception, mémoire, croyances, besoins, objectifs, utilité, intention, action) exécuté à chaque tick (SYNE-010).

    WriteBook(Book)

    Écrit un livre (SYNE-121, décision n°18, Monographie §3.18) : l'auteur (cognition requise) paie le coût d'écriture posé en principe — énergie world.books.writeCostEnergy débitée de ses besoins corporels (Needs ; durée de rédaction et pénalité non modélisées en V0.1) ; le livre est poinçonné (writtenTick = tick courant) et ajouté au monde. Mutation tracée dans LastBookChanges. API de la boucle — 0 tirage PRNG (déterministe, DETERMINISM.md §3).
