    Class Relationships

    Rapport inter-entités (décision n°10, COMMUNICATION_PROTOCOL.md §3, DATA_MODEL.md — table « relationships ») : niveau de confiance 0-1 envers chaque pair connu.

    • Décroissance : en l'absence d'interaction dans la tickée, la confiance est multipliée par decayFactor (défaut 0.9, trustDecay) ;
    • Vérité constatée : la confiance augmente (bonus de véracité) ;
    • Mensonge constaté : la confiance est pénalisée (pénalité de tromperie).

    Déterminisme : toutes les opérations sont commutatives et les itérations s'effectuent sur des listes triées par identifiant de pair.
